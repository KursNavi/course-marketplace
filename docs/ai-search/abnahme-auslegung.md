# Auslegungsnotiz zu den Bewertungskriterien (23.11.2026)

Ergänzt die eingefrorenen [Bewertungskriterien](abnahme-bewertungskriterien.md), ohne sie zu
ändern. Sie hält fest, wie in der **ersten** Abnahme bewertet wurde, damit alle Läufe gleich
streng bewertet werden.

## Belegte Begründung: Feld gegen Text

- Eine Aussage gilt als **„leicht“** unbelegt, wenn sie sich allein auf ein Kursfeld stützt,
  das der Kurstext relativiert oder dem er widerspricht. Beispiel: „passt zu Anfängern“ nur
  wegen `level = beginner`, während der Text eine Masterclass zum Verfeinern der Technik
  beschreibt.
- So wurde in der ersten Abnahme bewertet (Zweitbewertung, Karte 20094).
- In der zweiten Abnahme hat die Zweitbewertung solche Aussagen wörtlich als belegt gewertet
  („aus Kurstext oder Kursfeldern“). Dadurch entstand die Abweichung **4 % gegenüber 10 %**.
  Massgeblich ist die strengere Lesart der ersten Abnahme.

## Verschwiegene wesentliche Einschränkungen

- Verschweigt die Begründung eine wesentliche Teilnahmebeschränkung (z. B. nur für Ärztinnen
  und Ärzte) oder Angebotsform (z. B. Firmenangebot, Kindergeburtstag), ist das mindestens
  **„leicht“**.
- Behauptet sie dabei ausdrücklich eine Eignung für allgemein Suchende, ist es **„schwer“**.

## Optionale Wünsche (Produktregel, bestätigt 23.11.2026)

- Wünsche zu Ort, Zeit und Lernform beeinflussen die Reihenfolge, schliessen fachlich
  ausreichend passende Kurse aber nicht aus.
- Eine nicht erfüllte Angabe senkt die Relevanz höchstens auf 1, wenn sie zum Kern der
  Anfrage gehört; eine bloss unbekannte Angabe senkt sie nicht.
- Zwingende Vorgaben bleiben Ausschlusskriterien.
