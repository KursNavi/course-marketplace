# Frühere Ablage für Themenwelt-Arbeitsmappen

Neue und überarbeitete Themenwelten liegen nicht mehr in diesem technischen Dokumentationsordner. Die verbindliche, gut sichtbare Ablage ist:

```text
C:/Projects/KursNavi/Themenwelten/<Themenname>/
```

Dort trennt jede Arbeitsmappe `Input/`, die in Admin-Reihenfolge sortierten Review-Inhalte unter `Inhalt/` und das maschinenlesbare Paket unter `Uebergabe/`.

Der verbindliche Ablauf steht in `../workflow/README.md`.
